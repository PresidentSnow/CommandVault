# COMMIT CMD

## Help

* git help commit

## Options

* git commit (ci) -m | --message ""
* git commit (ci) -a | --all
* git commit (ci) --amend -m - replace the tip of the current branch by creating a new commit.
* git commit (ci) --amend --author="johndoe <johndoe@gmail.com>" --no-edit - replace the origin author of the commit.
