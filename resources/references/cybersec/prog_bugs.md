# PROGRAMMING BUGS

* **ORIGINAL DATE:** 2025/12/26

## THE MOST COMMON

* Buffer overflow
* Buffer underflow
* Use-After-Free (UAF)
* Double Free
* Memory Leak

## CONCURRENCY BUGS

* Time Of Check, Time Of Use (TOCTOU)
* Race condition
* Deadlock
* Livelock
* Data race

## LOGICAL BUGS

* Off by one
* Invalid state not contemplated

## INITIALIZATION BUGS

* Uninitialized variable

## RESOURCE BUGS

* File descriptor leak
* Use of resources in the wrong context

## SPECIAL BUGS

* Heisenbugs
* Bugs by UB (Undefined behavior)
