# PROGRAMMING BUGS

* **ORIGINAL DATE:** 2025/12/26

## The most common

* Buffer overflow
* Buffer underflow
* Use-After-Free (UAF)
* Double Free
* Memory Leak

## Concurrency bugs

* Time Of Check, Time Of Use (TOCTOU)
* Race condition
* Deadlock
* Livelock
* Data race

## Logical bugs

* Off by one
* Invalid state not contemplated

## Initialization bugs

* Uninitialized variable

## Resource bugs

* File descriptor leak
* Use of resources in the wrong context

## Special bugs

* Heisenbugs
* Bugs by UB (Undefined behavior)
