## Types

* **For general development:**

* feat: - New feature or functionality
* fix: - Bug fix
* docs: - Documentation/comments changes
* style: - Formatting changes (spaces, semicolons, etc.) without affecting logic
* refactor: - Restructuring code without changing its functionality
* test: - Adding or modifying tests
* chore: - Maintenance tasks (updating dependencies, configurations) or reorganize folder structure
* perf: - Performance improvements
* ci: - Continuous integration related
* build: - Changes that affect the build system or external dependencies
* revert: - Reverts a previous commit
* templates: - templates for git, terminals, yaml files, etc

* done:

## Specific for classes/learning

* class: - Class code/course exercise
* exercise: - Solution for a specific exercise
* example: - Demonstrative example
* practice: - Personal practice
* wip: (Work in Progress) - Incomplete partial changes
* rename: change files name
